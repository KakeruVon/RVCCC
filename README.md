# RVCCC - RISC-V Core Controlled CNN accelerator
An SoC Project on FPGA featuring a RISC-V CPU core with a CNN accelerating module. Successfully implemented on Zynq-7020. Got the original project structure from https://github.com/dev-the-desai/RISC-V-Core-with-Integrated-CNN-Accelerator by dev-the-desai, and it has been enriched in multiple ways.
